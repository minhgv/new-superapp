## Research context

The input context was the `Software Info` tab (`gid=58086397`) of the provided Alibaba Cloud Superapp POC resource sheet. The POC references Alibaba Cloud SuperApp Business Application Platform, WindVane Mini App, an Application Open Platform, native miniapp containers and Android/iOS/Flutter integration.

Credentials and private access details from the source sheet were intentionally excluded.

## Evidence policy

- Normative standards and primary official sources are labeled separately from vendor/platform practice.
- Recommendations are explicitly labeled as proposals; they are not presented as universal requirements.
- Public evidence gaps are retained as gaps rather than filled with assumptions.
- The research used Deli Deep with source validation and append-only evidence state.
